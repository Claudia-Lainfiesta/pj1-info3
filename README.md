# Java Maze Solver & Pathfinder

Un resolvedor de laberintos desarrollado en Java que utiliza algoritmos de búsqueda y estructuras de datos para encontrar la ruta de salida desde un punto de origen dentro de un laberinto.

## Características
- **Modelado con POO:** Representación eficiente del tablero y sus conexiones mediante nodos (`Node.java`) y matrices (`Maze.java`).
- **Resolución Automatizada:** Algoritmo de búsqueda (`Solver.java`) enfocado en la exploración del laberinto.
- **Casos de prueba:** Incluye lectura de archivos de texto con laberintos de distintas dimensiones y la verificación de sus rutas.

## Tecnologías utilizadas
- **Lenguaje:** Java
- **Conceptos:** Programación Orientada a Objetos (POO), Algoritmos de Búsqueda y Estructuras de Datos (Grafos/Matriz).

## Estructura del Proyecto
├── Maze.java       # Carga y representación del laberinto  
├── Node.java       # Definición de celdas/nodos  
├── Solver.java     # Algoritmo de resolución
